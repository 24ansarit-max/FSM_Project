Before generating RTL for a microwave oven controller, do the following:



Identify all inputs and outputs (e.g., door_closed, start, stop, timer_set, timeout, magnetron_on, light_on, turntable_on, buzzer).

Define the required states of the controller (e.g., IDLE, DOOR_OPEN, READY, COOKING, PAUSED, DONE).

Define the state transitions — under what conditions does the controller move between states (e.g., door opened during cooking, timer reaching zero, stop pressed).

Identify corner cases (e.g., door opened mid-cook, stop pressed while idle, timer set to zero, power interruption).

Determine the reset behavior (what state and outputs should reset to).



Then generate synthesizable SystemVerilog RTL implementing this design, consistent with the states and transitions identified above.
