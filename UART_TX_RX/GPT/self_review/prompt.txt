Step 1 — Generation:
Design a parameterized UART controller (transmitter + receiver) in synthesizable SystemVerilog.

Parameters: CLK_FREQ_HZ, BAUD_RATE, DATA_BITS (7/8), PARITY_MODE (none/even/odd), STOP_BITS (1/2).
TX states: Idle, Start, Data, Parity, Stop, Done. RX states: Idle, Start Detect, Data, Parity, Stop, Error/Done.
Inputs: clk, rst, tx_start, tx_data, rx_serial_in.
Outputs: tx_serial_out, tx_busy, tx_done, rx_data, rx_valid, framing_error, parity_error, overrun_error.

Generate the complete RTL code for this design.

Step 2 — Review:
Now review the RTL you just generated against the original specification. Explicitly check each of the following and report any issues found:
- Functional correctness (does the TX frame match start / LSB-first data / parity / stop? Does the RX recover exactly the transmitted byte?)
- Parameterization (are baud divider, oversampling counters, DATA_BITS, and bit counter widths truly parameterized, or are values like 868 or 8 hardcoded?)
- Baud timing (is the divider computed correctly for CLK_FREQ_HZ / BAUD_RATE, and is the rounding error acceptable? Is the RX sampling point truly at bit midpoint?)
- Signed/unsigned handling (any counters that could underflow or overflow, e.g., bit index, baud counter?)
- Reset behavior (does synchronous reset return both FSMs to Idle, drive tx_serial_out high, and clear all flags and counters?)
- FSM completeness (are all states reachable in both FSMs? Is the Parity state correctly skipped when PARITY_MODE = none? Any deadlock state?)
- Corner cases:
   - False start bit / line glitch
   - tx_start asserted while busy
   - Framing error (stop bit low) and break condition (line held low)
   - Parity mismatch for even and odd modes
   - Overrun (new byte arrives before previous is read)
   - Back-to-back frames with no idle gap
   - STOP_BITS = 2 and DATA_BITS = 7
- Metastability (is rx_serial_in synchronized with at least 2 flip-flops before use by the FSM?)
- Handshake correctness (are tx_done and rx_valid single-cycle pulses? Are outputs registered and glitch-free?)
- Synthesizability (any non-synthesizable constructs or duplicated counters/shift registers?)
- Unintended latches (any incomplete if/case statements in combinational blocks?)
- Width mismatches (implicit truncation or extension in counters, shift registers, and comparisons?)

Step 3 — Correction:
