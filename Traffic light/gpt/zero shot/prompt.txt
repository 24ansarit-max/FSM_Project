Design a parameterized 4-way (cross) intersection traffic light controller in synthesizable SystemVerilog, driven by an FSM.

Approaches: North, East, South, West. Each approach has Red, Yellow, and Green lights.
FSM states: N_Green, N_Yellow, E_Green, E_Yellow, S_Green, S_Yellow, W_Green, W_Yellow, All_Red (clearance interval between phases), Fault_Flash.

Requirements:
- Parameters: CLK_FREQ_HZ, GREEN_TIME_SEC, YELLOW_TIME_SEC, ALL_RED_TIME_SEC.
- Inputs: clk, rst, emergency_vehicle, fault_detect, pedestrian_request[3:0] (one per approach).
- Outputs: light_N[2:0], light_E[2:0], light_S[2:0], light_W[2:0] (encoded as {R,Y,G}), pedestrian_walk[3:0], current_state display.
- Phase sequence: N -> E -> S -> W -> N, with a yellow and an All_Red clearance interval between every green phase.
- Safety rule: two approaches must NEVER show green at the same time, under any state or input condition.
- Include a timer/counter derived from CLK_FREQ_HZ for each phase duration.
- Handle: emergency vehicle override (force all red, then hold or serve the requested approach), fault_detect (flash red on all approaches), and pedestrian requests (serve the walk signal only during the matching green phase).
- Provide the complete RTL code and explain the design, including the state transitions and the timing logic.
