
### SPECIFICATION
Design: Simple Traffic Light Controller (baseline test)
States: RED, GREEN, YELLOW (cyclic transition)
Optional feature: Pedestrian signal (WALK during RED, DON'T WALK otherwise)

### INTERFACE
- input clk
- input reset
- output red, yellow, green
- output walk, dont_walk (optional, include if pedestrian feature requested)

### BEHAVIOR
| Current State | Next State | Duration Control |
|---|---|---|
| RED | GREEN | counter reaches RED_TIME |
| GREEN | YELLOW | counter reaches GREEN_TIME |
| YELLOW | RED | counter reaches YELLOW_TIME |

### DESIGN RULES
- Style: Behavioral Verilog (always block + case statement)
- Reset: synchronous, active-high, returns FSM to RED and counter to 0
- Counter: simple up-counter, resets when target duration is reached
- No latches, no combinational feedback loops
- Verilog-2001 syntax, fully synthesizable

### DELIVERABLE
Output one complete Verilog module named `traffic_light_controller` implementing the above, with:
1. Parameter/localparam definitions for states and durations
2. State register and counter logic (always block)
3. Output logic for red/yellow/green (and walk/dont_walk if included)
4. Inline comments explaining each section

Output only the final Verilog code.
