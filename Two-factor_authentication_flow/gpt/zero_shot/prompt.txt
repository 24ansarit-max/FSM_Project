Design a synthesizable SystemVerilog FSM-based controller for a Two-Factor Authentication flow with the following states:
Password Entry, Password Verified, OTP Sent, OTP Verify, Access Granted, Locked (after failed attempts).

Requirements:
- Inputs: password_valid (comparison result), otp_valid (comparison result), otp_timeout, submit signal, reset.
- Outputs: request_otp (trigger OTP send), access_granted, locked_out, retry_count/display.
- The design must enforce a maximum retry limit for both password entry and OTP verification (e.g., 3 attempts each), and must transition to Locked if the limit is exceeded.
- The design must handle OTP timeout (if OTP is not verified within a time window, treat as failed attempt).
- Provide the complete RTL code and explain the design, including all state transitions and the retry/lockout logic.
