I want you to design a Two-Factor Authentication (2FA) Flow Controller FSM in synthesizable SystemVerilog. 
Before writing any RTL, think through the design step by step:

1. Identify all inputs and outputs (password_valid, otp_valid, otp_timeout, submit, retry limit parameter, request_otp, access_granted, locked_out, attempt counter/display, etc.)
2. List all states: Password Entry, Password Verified, OTP Sent, OTP Verify, Access Granted, Locked.
3. Define the state transition conditions for each state, especially:
   - What moves Password Entry -> Password Verified vs. back to Password Entry (retry) vs. -> Locked (limit exceeded)?
   - What triggers Password Verified -> OTP Sent?
   - What moves OTP Verify -> Access Granted vs. back to OTP Sent/OTP Verify (retry) vs. -> Locked?
   - How does an OTP timeout affect the retry count?
4. Identify corner cases (e.g., correct password but OTP always fails, OTP timeout counted as a failed attempt, retry counter reaching the limit exactly on the last allowed attempt, what happens on reset while Locked, whether Locked requires a timeout period or external reset to exit).
5. Define reset behavior (synchronous reset, default state, clearing retry counters).
6. Only after completing the above steps, generate the synthesizable SystemVerilog RTL implementing this FSM.

Show your reasoning for each step before presenting the final RTL code.
