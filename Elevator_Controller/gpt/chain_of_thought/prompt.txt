"Before generating RTL for an elevator controller, go through the following design stages explicitly:

Identify inputs and outputs (floor request buttons, current floor sensor, up/down limit switches, door sensor; motor up/down, door open/close, current floor display, direction indicator).
Define the required states/operations (IDLE, MOVING_UP, MOVING_DOWN, DOOR_OPENING, DOOR_OPEN, DOOR_CLOSING).
Define state transitions (how floor requests and sensor inputs trigger movement, stopping, and door operations).
Identify corner cases (simultaneous requests from multiple floors, request for current floor, request while doors are open, obstruction during door close, request above top floor/below ground floor).
Determine reset behavior (initial floor, door state, and pending requests on reset).

Specification → States → Transitions → Outputs → RTL

Then generate synthesizable SystemVerilog for the elevator controller based on this analysis."
