   - motor_up
   - motor_down
   - door_open_out
   - door_close_out
   - current_floor [$clog2(NUM_FLOORS)-1:0]
   - state_out [2:0]  // for simulation/debug visibility

   - If door_obstacle is high while closing, return to DOOR_OPEN.
   - From DOOR_CLOSED, check remaining requests: if requests exist in the current direction, continue that direction; else if requests exist in the opposite direction, reverse; else go IDLE.
7. Do not use any non-synthesizable constructs (no initial blocks for logic, no delays with #).
8. Include clear comments for every state and every conditional branch.
9. Output only the Verilog code, followed by a short explanation (max 5 lines) of the request-queue and direction-reversal logic.
