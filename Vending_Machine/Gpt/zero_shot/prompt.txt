Design a synthesizable SystemVerilog FSM-based controller for a Vending Machine with the following states:
Idle, Coin Inserted, Item Selected, Dispensing, Change Return, Out-of-Stock/Error.

Requirements:
- Track total coin value inserted (support multiple coin denominations, e.g., 1, 2, 5, 10 units).
- Allow item selection only after sufficient coins are inserted.
- If selected item is out of stock, transition to Error state and refund inserted coins.
- If inserted amount exceeds item price, compute and return correct change.
- Include inputs for coin values, item selection, item price, stock availability.
- Include outputs for dispense signal, change amount, error/out-of-stock indicator.

Provide the complete RTL code and explain the design, including all state transitions.
