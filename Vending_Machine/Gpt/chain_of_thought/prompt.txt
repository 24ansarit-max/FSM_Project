I want you to design a Vending Machine Controller FSM in synthesizable SystemVerilog.
Before writing any RTL, think through the design step by step:

1. Identify all inputs and outputs (coin input value, coin valid pulse, item select, item price, item stock status, dispense output, change output, error output, etc.)
2. List all states: Idle, Coin Inserted, Item Selected, Dispensing, Change Return, Out-of-Stock/Error.
3. Define the state transition conditions for each state, especially:
   - When does the machine move from Idle to Coin Inserted?
   - What condition allows moving from Coin Inserted to Item Selected (sufficient balance)?
   - What happens if the selected item is out of stock?
   - What happens if inserted amount is insufficient for the selected item?
   - How does the machine decide to enter Change Return vs go straight back to Idle?
4. Identify corner cases (e.g., coin inserted but no item selected within timeout, item selected but insufficient funds, item goes out-of-stock mid-transaction, multiple coins inserted rapidly, exact change vs overpayment).
5. Define reset behavior (synchronous reset, clearing balance and returning to Idle).
6. Only after completing the above steps, generate the synthesizable SystemVerilog RTL implementing this FSM.

Show your reasoning for each step before presenting the final RTL code.
